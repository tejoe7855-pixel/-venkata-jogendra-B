CAMPUS CONNECT — Student Dashboard Demo

FILES
- index.html: page structure
- style.css: responsive design and light/dark themes
- script.js: navigation, charts, timetable, filters, sample data and interactions

HOW TO RUN
1. Extract campus_connect_dashboard.zip.
2. Open the campus_connect folder.
3. Double-click index.html, or open the folder in VS Code.
4. For the best development experience, use the VS Code Live Server extension.

NOTES
- This is a front-end demonstration only. All student information and academic records are fictional sample data.
- No real authentication, college database, or server-side storage is connected.
- Google Fonts and Lucide icons load from the internet.
- Marksheets can be downloaded as a sample CSV file.
